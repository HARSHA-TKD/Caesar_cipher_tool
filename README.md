🔐 Caesar Cipher Tool

A beginner-friendly Python cryptography project demonstrating Caesar cipher encryption, decryption, and brute-force analysis.

✨ Features

- 🔒 Encrypt and decrypt messages
- 💥 Brute-force all 26 possible shifts
- 🔤 Preserve uppercase and lowercase letters
- 🧩 Keep spaces, numbers, and punctuation unchanged
- 🔄 Support negative and large shift values
- 🎨 Interactive terminal interface
- 🧪 Automated unit tests using Python's "unittest"

🛠️ Requirements

- Python 3
- No external packages required

🚀 Getting Started

Clone the repository:

git clone https://github.com/HARSHA-TKD/caesar-cipher-tool.git
cd caesar-cipher-tool

Run the application:

python caesar_cipher.py

🧪 Run Automated Tests

python -m unittest -v test_caesar_cipher

📚 Example

Original message: "HELLO WORLD"

Shift: "3"

Encrypted message: "KHOOR ZRUOG"

🔍 How It Works

The Caesar cipher shifts each alphabetic character by a specified number of positions, wrapping around the alphabet when necessary.

⚠️ Security Disclaimer

The Caesar cipher is an educational cryptography technique and is not suitable for protecting real passwords, credentials, or confidential information.
